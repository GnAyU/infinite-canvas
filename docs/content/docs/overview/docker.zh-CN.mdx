# Docker 部署

如果你希望在自己的机器或服务器上运行项目，可以直接使用 Docker Compose。

## 使用发布镜像

```bash
git clone git@github.com:basketikun/infinite-canvas.git
cd infinite-canvas
docker compose up -d
```

启动后访问：

```text
http://localhost:3000
```

## 本地构建镜像

如果需要基于当前源码构建镜像：

```bash
docker compose -f docker-compose.local.yml up -d --build
```

## 文档站镜像

文档站位于 `docs/` 目录，按带服务端能力的 Next.js standalone 应用单独构建，不打进主应用镜像。

使用发布镜像：

```bash
cd docs
docker compose up -d
```

基于当前源码本地构建：

```bash
cd docs
docker compose -f docker-compose.local.yml up -d --build
```

## 数据说明

当前主应用镜像只启动 Next.js。画布、我的素材、生成记录和 AI API Key 默认保存在浏览器本地；第三方提示词由浏览器前端直连拉取，不需要额外挂载数据目录。

## 统计分析（可选）

统计、自动版本检查、提示词源自动刷新及图片均默认关闭，用户须在「偏好设置」分别明确同意，仅本次页面会话有效。刷新页面或导入配置不会开启这些选项。配置统计 ID 不等于用户同意；镜像启动时只生成可用服务及强制关闭项的运行期配置。

统计按每家一个独立变量配置，仅支持 GA4 与百度；两者只接受 ID，脚本地址固定拼接，不接受任意脚本地址或内联 JS。填写 ID 不会自动加载脚本。

| 变量 | 说明 |
| --- | --- |
| `ANALYTICS_GA4_ID` | Google Analytics 4 衡量 ID（`G-XXXX`） |
| `ANALYTICS_BAIDU_ID` | 百度统计站点 ID（`hm.js?` 后面那串 hash） |
| `DISABLE_ANALYTICS` | `true` 强制关闭统计 |
| `DISABLE_VERSION_CHECK` | `true` 强制关闭自动版本检查 |
| `DISABLE_PROMPT_FEED` | `true` 强制关闭提示词源自动刷新及图片 |

在 `docker-compose.yml` 的 `environment` 中配置（文件内已附注释示例），下例配置 GA4 与百度，仍需用户会话内同意：

```yaml
services:
  app:
    image: ghcr.io/basketikun/infinite-canvas:latest
    ports:
      - "3000:3000"
    environment:
      ANALYTICS_GA4_ID: G-XXXXXXXXXX
      ANALYTICS_BAIDU_ID: xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

或使用 `docker run`：

```bash
docker run -d -p 3000:3000 \
  -e ANALYTICS_GA4_ID=G-XXXXXXXXXX \
  -e ANALYTICS_BAIDU_ID=xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx \
  ghcr.io/basketikun/infinite-canvas:latest
```

构建时也支持 `VITE_DISABLE_ANALYTICS`、`VITE_DISABLE_VERSION_CHECK`、`VITE_DISABLE_PROMPT_FEED`；任一层设置 `true` 都优先拒绝，部署不能强制用户同意。手动检查更新和刷新提示词显示目标地址，仅点击时联网。插件目录刷新及已安装、本地和开发插件加载需在管理器内主动操作；该门禁不代表 WEB-C 的代码信任机制已完成。

同意统计后仅传递静态路由或模板，不发送原始查询、片段、完整页面地址、渠道名、用户标题或生成文本。第三方统计脚本运行在无父页面访问权的隔离不透明来源 iframe 内；关闭统计会移除整个上下文。模拟验收不能证明真实服务商兼容性，Docker 部署仍待单独验证。

不要生成或分享带密钥的查询链接，请在渠道设置中输入凭据。兼容旧入口时，页面在资源、路由及统计初始化之前同步捕获支持的值到内存并清理 URL；新渠道不自动选中，密钥不持久化，按原样精确端点绑定（根路径与 `/v1` 不同）。Agent bootstrap 直接丢弃。**查询凭据在首次导航时已经到达托管服务器；客户端清理不能追溯清除服务器日志。**

<Callout type="warn">
请只在你自己的站点上配置统计 ID，不要把 ID 提交进仓库；fork 或自托管本项目的用户默认不会产生任何统计。
</Callout>
