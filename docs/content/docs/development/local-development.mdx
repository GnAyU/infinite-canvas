# Local Development

The main application lives in `web/`. The browser sends AI requests directly to the user's OpenAI-compatible endpoint.

## Start the frontend

```bash
cd web
bun install --frozen-lockfile
bun run dev
```

Use Bun 1.4.4 / Node 22.23.4. Open `http://127.0.0.1:3000`, then enter your `Base URL`, `API Key`, and model names in Settings. Prompt sources and WebDAV are also accessed directly by the browser. Standard scripts and explicit LAN opt-in are documented in the repository's `FORK.md`.

## Start the documentation site

```bash
cd docs
bun run dev
```

Common locations:

- Canvas, pages, and interactions: `web/`
- Prompt caching: `web/src/services/api/prompts.ts`
- Documentation content: `docs/content/docs/`
